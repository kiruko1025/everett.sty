\addchap{About these notes}
This small book is both a starting point for mathematical writing and a
collection of working examples. It includes definitions and proofs, equations,
diagrams, a plot, an algorithm, source code, exercises, and a bibliography.
Replace the sample material with your own chapters as the collection grows.

The style package controls the presentation; the separate macro package
provides mathematical shorthand. Project-specific notation belongs in
\texttt{macros/macros.tex}. Build instructions and installation details are in
the repository's \texttt{README.md}.
